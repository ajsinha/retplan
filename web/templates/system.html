Switching to PostgreSQL

  1. Create an empty database: createdb retplan
  2. Set url = "postgresql+psycopg://user:password@host:5432/retplan" under [database] in config/retplan.toml, or export RETPLAN_DATABASE_URL.
  3. Restart. The schema is created from schema/postgres.sql.
